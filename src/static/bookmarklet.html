Send to KYC

Store the LinkedIn profile you're already looking at in the Elvey KYC app. It only reads that page — no automation, no Claude, no tokens, and it doesn't count against the harvest's daily cap.

⇪ Send to KYC
  1. Drag the blue Send to KYC button onto Chrome's bookmarks bar (Ctrl+Shift+B shows the bar).
  2. Open anyone's LinkedIn profile in your normal Chrome, scroll once so Experience loads, then click the bookmark.
  3. It saves straight to the matching contact; if it can't tell who it is, a small window asks you to pick or create the contact.

The KYC dashboard must be running (scripts\run_kyc.ps1 or python -m src.dashboard). If you change the dashboard port, re-install the bookmark from this page. Waiting captures: /capture · People Tree
